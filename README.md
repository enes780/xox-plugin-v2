🛠 Kurulum ve Yapılandırma
Eklentiyi sorunsuz bir şekilde kurmak için aşağıdaki adımları takip edin:

Dosyayı İndirin: Eklentinin güncel .jar dosyasını temin edin.

Dosya Aktarımı: İndirdiğiniz dosyayı sunucunuzun kök dizinindeki /plugins klasörünün içine atın.

Başlatma: Sunucunuzu başlatın. Eklenti, ilk açılışta gerekli ayar dosyalarını (config.yml vb.) otomatik olarak oluşturacaktır.

Ayarlar: /plugins/XOXPlugin klasörüne giderek eklenti özelliklerini sunucunuza göre kişiselleştirebilirsiniz.

🔑 Lisans Aktivasyonu
Eklentinin tüm özelliklerini kullanabilmek için bir lisans anahtarına ihtiyacınız vardır:

Lisans Talebi: Yapımcı @rexste ile iletişime geçerek lisansınızı isteyin.

Otomatik Teslimat: Talebiniz üzerine lisans anahtarınız @rexste tarafından size iletilecektir.

Aktivasyon: Size iletilen anahtarı, eklenti klasöründeki .yml dosyasında bulunan ilgili lisans satırına yapıştırıp kaydedin. Ardından eklentiyi yenilediğinizde her şey hazır olacaktır!
